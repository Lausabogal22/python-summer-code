# Project 1 — Basic Python Mini‑Application

This mini‑project is a simple Python program designed to practice core programming concepts through a small, functional script.

## 🎯 Purpose
The goal of this project is to apply fundamental Python skills in a practical way, using:
- variables
- user input
- basic calculations
- conditional logic
- simple functions

## 🛠️ What the Program Does
This program performs a basic interactive task. It:
- asks the user for input
- processes the information using Python logic
- produces a clear output based on the user's response
